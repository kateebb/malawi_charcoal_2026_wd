Replication package for "Do coupled population, economic, and land use dynamics explain household energy transitions in Malawi?" (Beach et al., 2026) [published in World Development] 

All scripts used to process and analyze Malawi's Integrated Household Survey Waves II-V (IHS) and the Global Forest Cover Data v1.9 (GFCD) are included for transparency and replicability. We do not have permission to redistribute source files from the IHS and GFCD, so our replication dataset is a processed and integrated dataset from both original datasets.

Source data files can be found at:
- Malawi's IHS on the World Bank's Microdata Library:
https://microdata.worldbank.org/catalog/2307
https://microdata.worldbank.org/catalog/1003
https://microdata.worldbank.org/catalog/2936
https://microdata.worldbank.org/catalog/3818

- Global Forest Cover Data v1.9:
https://glad.earthengine.app/view/global-forest-change

To recreate our integrated analytical dataset using source files: Follow scripts 0a, 0b, 1a, 1b, and 2. 

Scripts 3a, 3b, 3c, 4, and 5 may be used to recreate analyses. These scripts include code to create Figures 2-5 and Tables 1, 2, and 3 in the main text. These scripts also include code to recreate appendix materials: Tables A2, A3, A4, and Figure A1.
